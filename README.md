# 🥗 Urban Food Supply Chain Management (Kelompok 5)

Selamat datang di repositori Proyek Akhir Mata Kuliah **Algoritma dan Struktur Data**. Sistem ini dirancang untuk mengelola rantai pasok makanan di area perkotaan dengan fokus pada efisiensi penyimpanan dan manajemen katalog produk.

---

## 🛠️ Fitur Utama
* **Katalog Produk Berbasis BST:** Pencarian dan pengelolaan produk menggunakan *Binary Search Tree*.
* **Sistem Peringatan Kadaluarsa:** Logika otomatis untuk mendeteksi stok yang mendekati masa expired.
* **Struktur Data Terintegrasi:** Menggunakan Linked List, Stack, dan Queue untuk manajemen distribusi.

---

## 📂 Struktur Direktori
Penyusunan folder mengikuti struktur yang telah disepakati:

| Folder / File | Deskripsi |
| :--- | :--- |
| `src/` | Folder utama kode sumber aplikasi. |
| `src/data_structures/` | Implementasi struktur dasar (Node, BST, dll). |
| `src/modules/` | Modul fitur aplikasi (Katalog Produk, Rantai Pasok, dll). |
| `AI_Log/` | Dokumentasi diskusi dan pemecahan masalah bersama AI. |
| `tests/` | File pengujian fungsionalitas kodingan. |
